## 📝 Sobre o Repositório

Este projeto contém a implementação das atividades propostas na primeira lista de PHP da disciplina. O objetivo principal é fixar a sintaxe da linguagem, lógica de programação básica e aplicar boas práticas de desenvolvimento no lado do servidor (Back-end).

---

## 🧠 Conceitos Fundamentais Aplicados

Durante o desenvolvimento das soluções desta lista, foram trabalhados os seguintes tópicos centrais da linguagem PHP:

1. **Variáveis e Tipagem Dinâmica:** Declaração e uso de variáveis (`$nomeVariavel`) para armazenar dados em memória.
2. **Operadores Aritméticos e Matemáticos:** Realização de operações como multiplicação, divisão, adição e exponenciação (`*`, `/`, `+`, `-`, `**`).
3. **Estruturas Condicionais:** Tomada de decisão no fluxo de execução com `if`, `elseif` e `else`.
4. **Operadores Lógicos e Comparadores:** Avaliação de condições múltiplas usando o operador E (`&&`) e operadores de comparação (`>=`, `<=`).
5. **Estruturas de Repetição (Laços):**
   * Controled por contador via `for`.
   * Iteração sobre estruturas de dados via `foreach`.
6. **Arrays (Vetores):** Manipulação de coleções indexadas de elementos em PHP.
7. **Funções com Parâmetros e Retornos:** Modularização de código reutilizável com `function`, passagem de argumentos e uso da instrução `return`.
