## 🧠 Conceitos e Aprendizados Aplicados

Nesta lista de exercícios foram abordados os pilares fundamentais da lógica de programação utilizando **PHP**:

- 🔹 **Manipulação de Variáveis e Tipos:** Declarações, atribuições e concatenações.
- 🔹 **Operadores Aritméticos:** Cálculos de multiplicação, divisão, potência (`**`) e percentuais.
- 🔹 **Estruturas Condicionais:** Uso de `if`, `elseif` e `else` para tomadas de decisões.
- 🔹 **Operadores Lógicos:** Avaliação de múltiplas condições com `&&` (AND).
- 🔹 **Estruturas de Repetição:** Laços `for` e `foreach` para iterações e percorrer dados.
- 🔹 **Vetores (Arrays):** Armazenamento de dados indexados e uso de funções agregadoras (`max()`, `min()`).
- 🔹 **Funções Personalizadas:** Sub-rotinas com passagem de parâmetros e valores de retorno (`return`).
