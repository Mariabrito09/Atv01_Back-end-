## 📝 Sobre o Repositório

Este repositório reúne os exercícios desenvolvidos para a **Lista 1 - Conceitos Básicos de PHP**, integrantes do plano de ensino do curso **Técnico em Desenvolvimento de Sistemas** da escola **SENAI "A. Jacob Lafer"**. 

O foco central das atividades é construir uma base sólida no desenvolvimento **Back-end**, abordando lógica de programação pura, manipulando estruturas de dados essenciais e aplicando sintaxes nativas da linguagem PHP de maneira eficiente, limpa e estruturada.

---

## 🧠 Conceitos Fundamentais Aplicados

Para a solução integral da lista de exercícios, foram explorados e colocados em prática os seguintes pilares da linguagem PHP:

| Conceito | Descrição & Aplicação no Projeto |
| :--- | :--- |
| **Variáveis & Tipagem** | Armazenamento de dados dinâmicos na memória (`$variavel`), manipulando números inteiros, ponto flutuante (*floats*) e textos (*strings*). |
| **Operadores Aritméticos** | Realização de cálculos matemáticos essenciais, como somas, multiplicações, divisões e potenciametria (`+`, `*`, `/`, `**`). |
| **Estruturas Condicionais** | Controle de fluxo através de blocos `if`, `elseif` e `else` para tomada de decisões lógicas. |
| **Operadores Lógicos & Comparadores** | Teste de condições compostas via operador **E** (`&&`) e operadores de comparação de grandeza (`>=`, `<=`). |
| **Laços de Repetição** | Repetição controlada por contadores (`for`) e iteração simplificada sobre vetores (`foreach`). |
| **Vetores (Arrays)** | Estruturação e armazenamento ordenado de conjuntos de dados. |
| **Funções & Escopo** | Modularização de código reutilizável (`function`), recebimento de parâmetros e retorno de valores via `return`. |
